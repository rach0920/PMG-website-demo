PMG homepage promotion image display fix

1. Extract this ZIP.
2. In https://github.com/rach0920/PMG-website-demo, choose Add file > Upload files.
3. Upload styles.css from the extracted folder to the repository root. Confirm GitHub says it will replace the existing styles.css.
4. Commit the change on main. Vercel should deploy automatically.
5. Refresh https://www.premiummg.com.au/ and check Agency Promotion Images.

This changes the display of promotion images so the portrait announcement is shown in full and centered. It does not replace or delete the Supabase announcement image.
